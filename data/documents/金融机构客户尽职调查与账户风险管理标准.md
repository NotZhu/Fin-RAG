# 金融机构客户尽职调查与账户风险管理标准

文档编号：FINRAG-STD-KYC-2026-001  
版本号：V1.0  
生效日期：2026-01-01  
适用范围：本标准适用于本机构境内营业网点、远程开户渠道、公司金融、零售金融、理财销售、电子银行、客户服务中心以及参与客户识别、账户管理、交易监测、风险评级和数据处理的外包服务团队。

## 1. 总则

### 1.1 制定目的

为规范客户身份识别、客户尽职调查、受益所有人识别、账户风险分类、交易监测、资料留存和个人金融信息保护工作，防范洗钱、恐怖融资、欺诈、账户出租出借、异常资金流转、产品错配和数据泄露风险，制定本标准。

### 1.2 基本原则

本机构开展客户管理应遵循以下原则：

1. 风险为本原则：根据客户身份、行业、地域、交易行为、产品使用、控制关系和历史风险事件进行差异化管理。
2. 审慎识别原则：客户身份资料不完整、证照过期、授权关系不清、受益所有人无法穿透识别时，不得简化办理。
3. 持续管理原则：客户开户后应持续监测交易行为、资料有效性、风险等级变化和异常事件。
4. 最小必要原则：收集和使用客户信息应限于业务办理、风险控制、合规审查和监管报送所需范围。
5. 可追溯原则：客户识别、审批、复核、评级调整、交易处置和人工干预过程应留痕，可供审计和监管检查。

### 1.3 关键定义

| 名称 | 定义 |
| --- | --- |
| 客户尽职调查 | 对客户身份、背景、业务目的、资金来源、控制关系和交易特征进行识别、核验、评估和持续更新的过程。 |
| 受益所有人 | 最终拥有或实际控制客户，或者享有客户最终收益的自然人。 |
| 增强尽调 | 对高风险客户或高风险业务采取更严格的资料核验、资金来源审查、管理层审批和交易限制措施。 |
| 账户风险分类 | 按账户用途、客户属性、交易行为和风险事件，将账户划分为正常、关注、限制、冻结或销户建议等状态。 |
| 异常交易 | 与客户身份、经营规模、资金来源、交易习惯明显不符，或具有拆分、快进快出、过渡账户、集中转入分散转出等特征的交易。 |

## 2. 组织职责

### 2.1 一线业务部门

一线业务部门负责客户接触、资料收集、真实性初审、业务目的确认、风险提示告知和客户回访。客户经理不得代客户填写核心身份信息，不得代客户点击风险揭示或产品确认按钮。

### 2.2 运营管理部门

运营管理部门负责账户开立、账户变更、印鉴管理、授权材料审核、影像归档、账户状态维护和资料有效期监控。对证照过期、授权失效、印鉴异常或开户资料缺失的客户，应及时发起补正流程。

### 2.3 合规与反洗钱部门

合规与反洗钱部门负责制定客户风险评级规则、维护高风险名单、审核增强尽调结果、组织可疑交易分析、推动监管报送和开展合规培训。涉及可疑交易报告的，应按照内部报告流程及时处理。

### 2.4 信息科技与数据安全部门

信息科技与数据安全部门负责系统权限、日志留存、数据加密、脱敏处理、接口安全、备份恢复和安全事件响应。测试环境不得使用未脱敏客户敏感数据。

## 3. 客户身份识别标准

### 3.1 个人客户身份识别

个人客户首次建立业务关系时，应至少核验以下资料：

1. 有效身份证件，包括居民身份证、护照、港澳居民来往内地通行证、台湾居民来往大陆通行证或监管认可的其他证件。
2. 客户姓名、证件号码、证件有效期、国籍、职业、联系方式、常住地址和税收居民身份声明。
3. 开户目的、预计交易规模、主要资金来源和主要交易渠道。
4. 是否为政要人士、政要人士关系人、高风险职业人员或受到制裁名单、负面新闻名单影响的人员。

身份证件已过期、证件号码与联网核查结果不一致、客户无法说明开户目的、联系方式明显异常或存在他人陪同操控情形的，应暂停开户并转入人工复核。

### 3.2 对公客户身份识别

对公客户首次建立业务关系时，应收集并核验以下资料：

1. 营业执照或登记证书。
2. 法定代表人或负责人身份证件。
3. 授权经办人身份证件及授权委托书。
4. 公司章程、合伙协议或其他能够反映股权和控制关系的文件。
5. 受益所有人信息表。
6. 经营地址证明、联系方式、主要经营范围、主要交易对手和预计交易规模。
7. 开户用途说明，涉及异地开户的，还应提供异地开户合理性说明。

对公客户如存在营业执照异常、经营地址无法核验、主要交易对手与经营范围不匹配、受益所有人识别不完整或授权链条不清晰，应采取增强尽调。

### 3.3 非面对面渠道识别

通过线上、远程、移动端、自助设备等非面对面渠道办理开户或关键业务时，应同时使用多因素核验手段，包括但不限于证件识别、人脸识别、银行卡绑定、手机号实名校验、设备指纹、地理位置风险识别和反欺诈规则。

非面对面开户出现下列情形之一的，应转人工审核：

1. 设备、手机号、银行卡或证件信息命中黑名单。
2. 同一设备短期内提交多个客户开户申请。
3. 人脸识别活体检测失败或疑似翻拍、屏幕攻击。
4. 客户开户目的与选择产品明显不一致。
5. 系统评分达到高风险阈值。

## 4. 受益所有人识别

### 4.1 识别路径

对公司类客户，应按照以下路径识别受益所有人：

1. 直接或间接拥有客户 25% 以上股权或表决权的自然人。
2. 通过协议、信托、代持、关联关系或其他安排实际控制客户的自然人。
3. 无法通过股权或控制关系识别时，识别高级管理人员中的主要负责人。

对合伙企业、基金、信托、社会组织等客户，应结合其组织形式识别最终控制人、管理人、委托人、受托人、受益人或实际享有收益的自然人。

### 4.2 穿透要求

受益所有人识别应穿透至自然人，不得仅停留在法人、合伙企业、信托计划或资管产品层面。股权结构超过三层、存在境外主体、信托安排、代持声明或循环持股的，应提交合规部门复核。

### 4.3 无法识别时的处置

客户拒绝提供受益所有人资料、提供资料明显矛盾、无法穿透识别最终自然人，或者受益所有人命中高风险名单的，应采取以下措施：

1. 暂停开户或限制账户功能。
2. 要求客户补充公司章程、股权结构图、控制关系说明和资金来源证明。
3. 提交合规部门审核。
4. 必要时拒绝建立业务关系或终止既有业务关系。

## 5. 客户风险评级

### 5.1 风险等级

客户风险等级分为五级：

| 等级 | 名称 | 说明 |
| --- | --- | --- |
| R1 | 低风险 | 身份清晰、交易稳定、产品简单、无异常记录。 |
| R2 | 较低风险 | 资料完整，交易规模与身份基本匹配，存在少量需关注因素。 |
| R3 | 中风险 | 行业、地域、交易结构或产品使用存在一定复杂性。 |
| R4 | 较高风险 | 存在高风险行业、异地经营、频繁现金交易、复杂控制结构或异常交易线索。 |
| R5 | 高风险 | 命中高风险名单、涉嫌账户出租出借、受益所有人不明、可疑交易明显或监管要求重点关注。 |

### 5.2 评级因素

客户风险评级至少考虑以下因素：

1. 客户身份和职业背景。
2. 行业属性和经营范围。
3. 注册地、经营地、交易对手所在地。
4. 受益所有人结构和控制链复杂度。
5. 产品和服务风险。
6. 交易金额、频率、渠道和交易对手。
7. 负面新闻、司法信息、监管处罚和名单命中情况。
8. 资料完整性和更新及时性。

### 5.3 评级调整

客户出现以下情形之一的，应在 10 个工作日内重新评级：

1. 客户身份资料发生重大变更。
2. 法定代表人、受益所有人或实际控制人发生变化。
3. 交易行为与历史习惯明显不一致。
4. 命中制裁、司法、反洗钱、欺诈或内部风险名单。
5. 发生投诉、司法冻结、监管协查或可疑交易分析事件。
6. 客户主动申请开通高风险产品或高风险交易渠道。

## 6. 增强尽调

### 6.1 触发条件

以下客户或业务应触发增强尽调：

1. R4、R5 风险等级客户。
2. 涉及高风险国家或地区的客户。
3. 现金密集型行业、虚拟资产相关业务、地下钱庄风险行业、空壳公司风险客户。
4. 股权结构复杂、受益所有人不明或存在代持安排。
5. 短期内频繁开销户、频繁变更法人或注册地址。
6. 交易存在拆分、快进快出、集中转入分散转出、分散转入集中转出等特征。

### 6.2 增强措施

增强尽调可采取以下措施：

1. 要求客户提供资金来源证明、经营合同、发票、物流凭证、纳税证明或审计报告。
2. 对经营地址、主要交易对手和实际经营情况进行电话、视频或现场核验。
3. 要求高级管理人员审批开户、产品开通或交易限制解除。
4. 提高交易监测频率，缩短客户资料更新周期。
5. 限制非柜面交易额度、限制高风险渠道或暂停部分账户功能。
6. 对异常交易开展可疑交易分析，必要时报送可疑交易报告。

### 6.3 审批要求

高风险客户建立业务关系、解除账户限制、开通高风险交易渠道或购买高风险金融产品，应经业务部门负责人、运营负责人和合规部门共同审批。审批意见应说明客户风险点、缓释措施、持续监控要求和下次复核时间。

## 7. 账户开立与变更

### 7.1 开户资料

对公账户开户应至少具备以下资料：

1. 营业执照。
2. 法定代表人身份证件。
3. 经办人身份证件和授权委托书。
4. 公司章程或股权结构说明。
5. 受益所有人信息表。
6. 开户申请书。
7. 印鉴卡。
8. 经营地址证明。
9. 异地开户合理性说明，适用于异地开户场景。

### 7.2 资料缺失处置

客户资料缺失、证照过期、授权文件不完整或受益所有人信息缺失时，应按以下规则处理：

1. 新开户业务不得提交最终开户。
2. 存量客户应通知补正，并设置合理补正期限。
3. 逾期未补正的，可限制非柜面交易、限制大额支付或暂停新增业务。
4. 涉及高风险客户的，应提交合规部门判断是否需要可疑交易分析。

### 7.3 账户变更

客户变更名称、法定代表人、注册地址、经营范围、受益所有人、授权经办人、印鉴或联系方式的，应重新核验相关材料。高风险客户发生关键身份信息变更的，应重新执行客户风险评级。

## 8. 交易监测与异常处置

### 8.1 监测规则

系统应对以下交易特征进行监测：

1. 与客户身份、职业、经营规模明显不符的大额交易。
2. 短期内集中转入后迅速分散转出。
3. 多个账户向同一账户集中转入，或同一账户向多个账户分散转出。
4. 交易金额频繁接近内部监测阈值。
5. 长期不动户突然发生大量交易。
6. 账户资金不留余额，呈现过渡账户特征。
7. 与高风险地区、异常商户或风险名单主体发生资金往来。

### 8.2 人工分析

命中监测规则不等同于可疑交易。分析人员应结合客户身份、业务背景、交易目的、资金来源、交易对手和历史行为进行综合判断。无法合理解释的，应升级合规部门复核。

### 8.3 可疑交易处理

可疑交易分析应形成书面记录，至少包括：

1. 客户基本信息。
2. 触发规则和交易明细。
3. 客户历史交易特征。
4. 资金来源和资金去向分析。
5. 客户解释及佐证材料。
6. 分析结论和处置建议。

需要报送可疑交易报告的，应按照监管要求和内部流程及时报送。不得向客户泄露可疑交易分析和报送信息。

## 9. 产品适当性与风险匹配

### 9.1 客户风险承受能力

销售理财、基金、贵金属、结构性存款、保险代理等产品前，应评估客户风险承受能力。客户风险承受能力等级包括 C1、C2、C3、C4、C5。

### 9.2 产品风险等级

产品风险等级包括 R1、R2、R3、R4、R5。销售原则如下：

| 客户等级 | 可匹配产品 |
| --- | --- |
| C1 | R1 |
| C2 | R1、R2 |
| C3 | R1、R2、R3 |
| C4 | R1、R2、R3、R4 |
| C5 | R1、R2、R3、R4、R5 |

客户风险承受能力低于产品风险等级的，不得主动销售。客户坚持购买超过其风险承受能力的产品时，应按监管和内部制度要求执行额外风险揭示、冷静期或禁止销售规则。

### 9.3 禁止行为

销售人员不得存在以下行为：

1. 承诺本金安全或固定收益。
2. 使用“保本”“稳赚”“无风险”等误导性表述。
3. 代客户抄录风险揭示、代客户签字或代客户点击确认。
4. 隐瞒产品费用、期限、流动性限制和主要风险。
5. 向不适当客户销售高风险产品。

## 10. 数据安全与资料留存

### 10.1 个人金融信息范围

个人金融信息包括客户身份信息、账户信息、交易信息、资产负债信息、信用信息、鉴别信息、金融产品购买信息、衍生分析信息和监管规定的其他敏感信息。

### 10.2 数据使用要求

客户数据使用应遵循授权、最小必要、分级访问和全程留痕要求。生产数据导出应经过审批，测试环境和开发环境不得使用未脱敏客户敏感数据。

### 10.3 留存期限

客户身份资料和交易记录应在业务关系结束后至少保存 5 年。涉及可疑交易、监管检查、司法协查、投诉纠纷或内部调查的资料，应保存至相关事项结束后再按规定计算留存期限。

### 10.4 数据共享

对外共享客户数据应满足以下条件：

1. 具有合同依据、监管依据或客户授权。
2. 明确共享目的、字段范围、保存期限和安全责任。
3. 对敏感字段进行加密、脱敏或最小化处理。
4. 留存审批记录、传输日志和接收方确认记录。

## 11. 操作风险与应急处置

### 11.1 重大事件

以下事项属于重大操作风险事件：

1. 客户身份资料批量泄露。
2. 账户被批量盗用或冒名开立。
3. 核心交易系统长时间中断。
4. 大量客户资金异常划转。
5. 监管机构要求立即说明或现场检查的重大合规事项。

### 11.2 报告时限

重大操作风险事件发现后，应在 2 小时内完成内部首报。首报内容包括事件时间、影响范围、初步原因、已采取措施、客户影响、监管影响和后续处置计划。

### 11.3 业务连续性

业务连续性管理应识别关键业务、关键系统、关键岗位、关键供应商和恢复时间目标。客户身份核验、账户控制、交易监测和监管报送属于优先恢复业务。

## 12. 内部检查与问责

### 12.1 检查频率

合规部门应至少每半年组织一次客户尽职调查和账户风险管理专项检查。高风险网点、高风险业务和近期发生重大风险事件的单位，应提高检查频率。

### 12.2 常见问题

检查中重点关注以下问题：

1. 客户资料缺失但账户仍正常使用。
2. 受益所有人识别停留在法人层面。
3. 高风险客户未执行增强尽调。
4. 异常交易分析结论缺乏证据支持。
5. 销售人员代客户完成风险揭示。
6. 测试环境使用未脱敏客户数据。

### 12.3 问责措施

对违反本标准的人员，可根据情节采取提醒、通报批评、绩效扣减、岗位调整、纪律处分或移送司法机关等措施。因管理不到位导致重大风险事件的，应追究直接责任、管理责任和监督责任。

## 13. 附录：测试问答样例

以下问题可用于检索和问答测试：

1. 对公客户开户需要提交哪些基础资料？
2. 受益所有人应按照什么路径识别？
3. 客户资料缺失或证照过期时，账户应该如何处理？
4. 高风险客户需要采取哪些增强尽调措施？
5. 哪些交易特征可能触发异常交易监测？
6. 测试环境能否使用未脱敏客户敏感数据？
7. 客户风险等级与产品风险等级如何匹配？
8. 重大操作风险事件发现后多久需要首报？
9. 销售理财产品时哪些话术或行为被禁止？
10. 对外共享客户数据需要满足哪些条件？

## 14. 附则

本标准由合规与反洗钱部门负责解释。各业务条线可在不低于本标准要求的基础上制定实施细则。本标准未尽事宜，按照监管规定和本机构其他制度执行。
