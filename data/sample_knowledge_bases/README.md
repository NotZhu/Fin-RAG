# Fin-RAG 企业级测试知识库样例

本目录包含三个英文默认知识库目录：

- `finance`：财报经营分析、收入确认、经营计划、行业研究、公告索引和测试问题。
- `risk_control`：授信尽调、贷后检查、评分卡、风险预警、审查纪要和测试问题。
- `compliance_legal`：反洗钱尽调、数据出境、SaaS合同、合同审查、风险条款和测试问题。

文件格式仅包含 `.md`、`.txt`、`.docx`、`.pdf`。其中 DOCX/MD/TXT 承载主要可检索语料，PDF 用于上传兼容性和版式类文件测试。全部公司、客户、编号、金额和案例均为模拟数据，不包含真实敏感信息。

建议测试方式：
1. 按目录分别创建三个知识库，测试分库检索。
2. 上传全部文件后测试跨文档问答，例如“经营分析和收入确认政策都提到哪些回款风险”。
3. 测试字段抽取，例如金额、期限、风险等级、审批条件、责任部门、复核频率。
4. 测试长文档分块召回，例如从授信尽调报告中定位担保措施、提款条件和贷后触发规则。

推荐测试问题：
- 示例集团2025年营业收入、归母净利润、经营现金流分别是多少？
- 经营分析简报和收入确认政策分别如何描述验收与回款风险？
- 华东智造设备有限公司的授信额度、担保方式、提款条件和贷后触发规则是什么？
- 小微企业贷后检查首次应在放款后多少日内完成，哪些情形需要提交风险预警？
- 哪些客户需要执行强化尽职调查，高风险客户的复核频率是什么？
- SaaS合同中责任限制的例外情形有哪些，合同审查清单要求如何区分法务意见？
